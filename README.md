**Descriptio**
>Marry My Dead Body is a Taiwanese movie about a homophobic cop, a gay ghost, and their relationship. The main character is a police detective prejudiced against the LGBTQ+ community. One day, a superstitious woman approaches the cop and ropes him into marrying her dead grandson.
